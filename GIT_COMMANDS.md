# Команды Git

## git init

Создаёт репозиторий в текущей папке.

```bash
git init
```

## git clone

Копирует репозиторий с GitHub на компьютер.

```bash
git clone https://github.com/KirillDP/git-lab.git
```

## git add

Подготавливает изменения файла для сохранения.

```bash
git add README.MD
```

## git commit

Сохраняет подготовленные изменения в истории репозитория.

```bash
git commit -m "Изменения в README"
```

## git push

Отправляет изменения ветки на GitHub.

```bash
git push origin git-commands
```

## git pull

Получает изменения из удалённой ветки и добавляет их в текущую ветку.

```bash
git pull origin main
```
